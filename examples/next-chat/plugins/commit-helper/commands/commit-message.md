Look at the changes in the working directory (`git status`, `git diff`; run `git init` first if
this is not a repository yet) and draft one commit message for them, following the
Conventional Commits skill. The scope is "$ARGUMENTS": when that is empty, leave the scope and its
parentheses out. Do not commit: answer with the message only.
