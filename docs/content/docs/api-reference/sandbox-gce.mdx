## `createGceNetworkSandboxSession(options)`

Creates a sandbox, a Compute Engine machine of its own, through the sandbox service and returns a `GceNetworkSandboxSession` on it. Besides the settings below, it takes `sandboxId`, `template` and `abortSignal`.

## `resumeGceNetworkSandboxSession(options)`

Reattaches to a running sandbox, or starts a stopped one again on its disk. Besides the settings below, it takes `sandboxId` (required) and `abortSignal`. Throws `GceSandboxNotFoundError` when no sandbox has that name.

## `prepareGceSandboxService(options)`

Has the sandbox service boot what the sandbox created next will need, without waiting for it: its egress proxy, when it starts and stops it, and a machine booted from the sandbox's template, which the creation takes. A hint: do not await it. It never builds the template, and a service of an earlier version boots the proxy only, or nothing.
