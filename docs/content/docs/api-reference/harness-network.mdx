## `networkPolicy(...lists)`

Returns `{ mode: 'custom', allowedHosts }`, the hosts of `lists` checked, in lower case, each once and sorted: the `networkPolicy` of a sandbox, or of `setNetworkPolicy()`. `allowedHosts(...lists)` returns the same list alone, and both throw an `InvalidHostError` for a host `isAllowedHost()` refuses.

## `trustedHosts(...names)`

The hosts of `TRUSTED_HOSTS` for each service named (`TrustedService`), or for the services of each group of `TRUSTED_GROUPS` (`TrustedGroup`); every service without any.

## `harnessHosts(harnessId, options?)`

What `HARNESS_NETWORK` holds for the harness: where it installs from, its service, and the API of its provider.
